## Projetos em equipe

### 🐾 Enlace — Rede de Adoção de Animais

Aplicativo mobile voltado à divulgação e à busca de animais disponíveis para adoção, aproximando interessados, protetores, ONGs e tutores.

O projeto aborda anúncios, filtros de pesquisa, favoritos, câmera, geolocalização e persistência local com sincronização.

**Tecnologias:** TypeScript, React Native, Expo, SQLite e Supabase.

[Ver repositório →](https://github.com/Christian-SoAssis/Projeto_DevMobile)

### 🛠️ ServiçoJá — Marketplace de Serviços Locais

Projeto de plataforma web para conectar clientes a prestadores de serviços, envolvendo cadastro de usuários, solicitações, propostas e avaliações.

O projeto reúne desenvolvimento de API, interface web, persistência de dados e planejamento de recursos de inteligência artificial.

**Tecnologias:** Python, FastAPI, TypeScript, Next.js, PostgreSQL e Docker.

[Ver repositório →](https://github.com/Christian-SoAssis/Projeto_ProgWeb)
